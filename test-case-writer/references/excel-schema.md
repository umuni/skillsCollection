# Excel 导出字段规范

## 字段顺序（不可更改）

```
["模块", "编号", "标题", "状态", "维护人", "用例类型", "重要程度", "测试类型",
 "预估工时", "剩余工时", "关联工作项", "前置条件", "步骤描述", "预期结果",
 "关注人", "备注", "适用阶段", "关联模块"]
```

## 固定规则

- **编号**：必须写入空字符串（不是测试用例的 TC-ID，那个只在生成过程和脚本内部用于追踪顺序）
- **步骤描述** / **预期结果**：写入对应的多行字符串（每行带编号，如"1. xxx"）
- **模块**：层级之间用"/"间隔，例如"一级模块/二级模块/三级模块"，最多3级
- **前置条件**：非必填，有则填写，无则留空字符串

## 必填字段

模块、标题、状态、维护人、用例类型、重要程度、测试类型、步骤描述、预期结果、适用阶段

## 必须保持为空的字段

编号、预估工时、剩余工时、关联工作项、关注人、备注、关联模块

## 默认值（配置区变量）

```python
OUTPUT_FILE = "test_cases.xlsx"
DEFAULT_OWNER = "宁瑞瑞"
DEFAULT_STATUS = "就绪"
DEFAULT_CASE_TYPE = "功能测试"
DEFAULT_TEST_TYPE = "手动"
DEFAULT_STAGE = "功能测试阶段"
```

> 如果用户告知了不同的默认维护人/状态/阶段等信息，以用户提供的为准，覆盖上面的默认值。

## 控制台输出格式

```
[1/N] 生成用例: TC-001 - xxx功能验证
```
