# 工时估算参考基线

这些数值仅用于用户没有历史数据时的暂估。先确认团队是否有自己的度量；不要把基线包装成事实。

## 复杂度系数

| 复杂度 | 系数 | 判定示例 |
|---|---:|---|
| 低 | 0.8 | 单角色、规则清晰、依赖稳定、复用成熟资料 |
| 中 | 1.0 | 多状态或少量依赖，存在常规异常分支 |
| 高 | 1.3-1.6 | 跨系统、多角色、资金/权限/数据一致性、高风险变更 |

## 参考单位耗时

| 事项 | 参考基线 | 固定准备时间 |
|---|---:|---:|
| 需求理解/评审 | 每功能点5-10分钟，或每主流程20-40分钟 | 0.25h |
| 用例设计 | 每功能点10-20分钟，或每条详细用例5-10分钟 | 0.25h |
| 用例评审 | 每20-30条用例0.5-1h | 0.25h |
| 环境部署 | 每服务/组件15-30分钟 | 0.25-0.5h |
| 数据准备 | 每数据组合5-15分钟 | 0.25h |
| 冒烟测试 | 每核心流程10-20分钟 | 0.25h |
| 功能测试 | 每条用例3-8分钟，复杂链路8-15分钟 | 0.25h |
| 接口测试 | 每接口15-30分钟；复杂鉴权/链路30-60分钟 | 0.25h |
| 兼容性测试 | 每平台组合20-40分钟/核心流程 | 0.25h |
| 缺陷复现与提交 | 每缺陷15-30分钟，复杂问题30-60分钟 | 0h |
| 缺陷验证 | 每缺陷10-20分钟，另加关联回归 | 0.25h |
| 自动化脚本 | 每简单用例0.5-1h，复杂用例1-3h | 0.5h |
| 预研与技术验证 | 每子任务1-3h；涉及新工具/跨系统读取2-4h | 0.5h |
| 测试报告 | 数据齐全时每模块15-30分钟 | 0.25h |

性能、安全和生产发布高度依赖环境及风险，不使用固定单位耗时直接承诺；先确认场景、指标、环境、工具、窗口和审批限制。

## 计算与取整

```text
净工时 = 固定准备时间 + 单位耗时 × 数量 × 复杂度系数
计划工时 = 净工时 × (1 + 风险缓冲率)
```

- 低风险缓冲10%，中风险20%，高风险30%。
- 结果按0.5小时向上取整。
- 明确区分实际动手时间和等待时间；等待构建或他人处理不计入净工时，但应标注依赖。
- 当单位数量未知时，不计算单点工时，先追问或给带前提的范围暂估。
