1. 先判断现有用例的实际步骤和预期是否已经覆盖 L1 意图，不能只比较标题。
2. 已覆盖的 L1 项不重复生成；适用但未覆盖的 L1 项新增独立测试点，并继续遵守原技能命名格式。

4. L1 补充发生在大纲锁定前，补充完成后才统一分配 `TC-001`、`TC-002`……并锁定数量。
